# EL-MESBAH — Architecture

Production web app for EL-MESBAH (software, AI, and automation solutions company).

## Stack

| Layer | Choice |
|---|---|
| Frontend | Next.js 15+ (App Router, React, TypeScript) |
| Styling | Plain CSS (tokens + reset + components) |
| Backend | Next.js Route Handlers (serverless) |
| Database | PostgreSQL (Phase 2) |
| ORM | Prisma (Phase 2) |
| Email | Resend (Phase 2) |
| Bot protection | Cloudflare Turnstile (Phase 2) |
| Hosting | Vercel |
